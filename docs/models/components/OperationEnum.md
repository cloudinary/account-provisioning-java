# OperationEnum

Specifies the operation to perform. Use `add` to associate or `remove` to disassociate.

## Example Usage

```java
import com.cloudinary.account.provisioning.models.components.OperationEnum;

OperationEnum value = OperationEnum.ADD;
```


## Values

| Name     | Value    |
| -------- | -------- |
| `ADD`    | add      |
| `REMOVE` | remove   |
