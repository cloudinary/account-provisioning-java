# PermissionTypeEnum

Specifies whether permissions apply globally or to specific content.

## Example Usage

```java
import com.cloudinary.account.provisioning.models.components.PermissionTypeEnum;

PermissionTypeEnum value = PermissionTypeEnum.GLOBAL;
```


## Values

| Name      | Value     |
| --------- | --------- |
| `GLOBAL`  | global    |
| `CONTENT` | content   |
