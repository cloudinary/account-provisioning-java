# QueryParamSortOrder

Control the order of returned users. **Possible values**: `desc` (default), `asc`.


## Example Usage

```java
import com.cloudinary.account.provisioning.models.operations.QueryParamSortOrder;

QueryParamSortOrder value = QueryParamSortOrder.DESC;
```


## Values

| Name   | Value  |
| ------ | ------ |
| `DESC` | desc   |
| `ASC`  | asc    |
