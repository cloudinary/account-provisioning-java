# SortBy

Which response parameter to sort by. **Possible values**: `api_key`, `created_at`, `name`, `enabled`.


## Example Usage

```java
import com.cloudinary.account.provisioning.models.operations.SortBy;

SortBy value = SortBy.API_KEY;
```


## Values

| Name         | Value        |
| ------------ | ------------ |
| `API_KEY`    | api_key      |
| `CREATED_AT` | created_at   |
| `NAME`       | name         |
| `ENABLED`    | enabled      |
