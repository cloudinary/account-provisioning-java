# SortOrder

Control the order of returned keys. **Possible values**: `desc` (default), `asc`.


## Example Usage

```java
import com.cloudinary.account.provisioning.models.operations.SortOrder;

SortOrder value = SortOrder.DESC;
```


## Values

| Name   | Value  |
| ------ | ------ |
| `DESC` | desc   |
| `ASC`  | asc    |
